À propos d'Analyse Interview IA

Version: 1.0

Description: Application web pour transcrire et analyser des interviews avec l'intelligence artificielle.

🔧 Technologies utilisées:

  • OpenAI Whisper - Transcription audio
  • Hugging Face T5 - Résumé de texte
  • Flask - Backend web
  • PyTorch - Framework IA

📋 Fonctionnalités actuelles:

  • ✅ Transcription audio en français
  • ✅ Résumé intelligent avec chunking
  • ✅ Extraction de mots-clés
  • ✅ Analyse d'émotions
  • ✅ Interface responsive

🚀 Prochaines améliorations:

  • 📚 Historique complet des interviews
  • 💾 Export des résultats (PDF, JSON)
  • 📥 Import de données
  • 👥 Gestion de profils multiples
  • 🎨 Thèmes personnalisés

Aide & Support

🎵 Comment utiliser l'onglet Audio?

1. Cliquez sur "Fichier Audio"
2. Sélectionnez un fichier .mp3
3. Cliquez sur "Analyser l'interview"
4. Attendez le traitement (quelques minutes)

📝 Comment utiliser l'onglet Texte?

1. Cliquez sur "Texte Direct"
2. Collez votre transcription
3. Cliquez sur "Analyser l'interview"

❓ Questions fréquentes

Q: Combien de temps prend l'analyse?
R: Entre 2 et 5 minutes selon la longueur de l'audio.

Q: Mes données sont-elles sauvegardées?
R: Les résultats restent dans votre navigateur (localStorage).

Q: Quels formats audio sont acceptés?
R: Actuellement .mp3 (d'autres formats peuvent être ajoutés).
